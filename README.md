### 👨‍💻 About Me & TN Dev Lab Studio

Welcome! I am **Raj**, a passionate software developer and the founder of **TN Dev Lab Studio**. 

At **TN Dev Lab Studio**, our core mission is engineering lightning-fast, resource-conscious, and aesthetically stunning desktop software that replaces bloated system utilities with pure, raw performance.

- 🏢 **Organization:** Founder & Lead Developer at **TN Dev Lab Studio**
- ⚡ **Core Philosophy:** Software should be instantaneous, lightweight (< 50 MB RAM budget), and respect system resources.
- 🚀 **Flagship Product:** **[Finder](https://github.com/rjppppppp/Finder)** — Ultra-fast, intelligent system-wide file & application search for Windows (macOS Spotlight / Raycast alternative).
- 🧠 **Areas of Expertise:** C# .NET 8, WPF, Win32 Native Interop, Low-latency Data Structures, Zero-allocation Fuzzy Search algorithms, and Sleek Modern Dark UI/UX.
- 🎯 **Current Focus:** Expanding high-performance desktop productivity tooling and open-source software.
- 💬 **Ask me about:** Desktop system architecture, C#, Windows API internals, caching algorithms, and performance profiling.
